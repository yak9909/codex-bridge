# codex-bridge 運用手順書（依頼主＝あなた向け）

知人の PC の Codex に、あなたの PC のフォルダで作業してもらうための手順です。
知人向けの手順は [friend-guide.md](friend-guide.md)（setup.bat が作る `friend-kit\使い方.md` と同じもの）です。

---

## A. 最初に一度だけ

事前に、この PC に Tailscale を入れてログインしておいてください（[C. Tailscale の準備](#c-tailscale-の準備)）。

### A-1. `setup.bat`

ダブルクリックして、画面の質問に答えます（Enter だけで、おすすめの設定になります）。

| 段階 | 起きること | あなたがすること |
|---|---|---|
| 1. Tailscale の確認 | この PC の Tailscale の IP を調べる | 未接続なら、案内に従ってログイン |
| 2. 検索用の部品 | ripgrep を用意 | なし |
| 3. 共有フォルダ | フォルダを選ぶ画面が開く | **Codex に触らせるフォルダを選ぶ**（あとで管理画面からも変えられます） |
| 4. ファイアウォール | Windows が「変更を許可しますか？」と聞く | **「はい」を押す** |
| 5. 知人に渡す一式 | `friend-kit` フォルダに exe と使い方を作る | なし |
| 6. 完了 | Tailscale の管理画面を開く | この PC の「…」→「Share...」→ 招待リンクを知人に送る |

### A-2. `install-mcp.bat`

Claude Code と Codex（入っているほう）に codex-bridge を登録します。これで、エージェントに頼むだけで使えるようになります。
Claude Code や Codex を後から入れたときは、もう一度実行してください。

### 知人に渡すもの

1. `friend-kit` フォルダの中身（`codex-bridge-agent.exe` と `使い方.md`）
2. Tailscale の共有の招待リンク（A-1 の段階 6 で作ったもの）
3. 招待コード: `start.bat` で起動 → 管理画面の「招待コード」→「発行」→ その場でコピー（再表示できません）

※ OpenAI の規約上グレーな使い方なので、知人に伝えて了解をもらってください。

## B. 毎回

### 起動と停止

- **`start.bat`** … 起動します。黒いウィンドウが開き、管理画面がブラウザで開きます。作業中はこのウィンドウを閉じず、PC もスリープさせないでください。
- **`stop.bat`** … 止めます（黒いウィンドウを閉じても止まります）。

管理画面の右上が「知人の agent に接続中」なら準備完了です（知人が codex-bridge を起動している必要があります）。

### 依頼のしかた（どれでも同じことができます）

**1. エージェントに頼む（おすすめ）**
Claude Code か Codex で新しい会話を始め、次のように頼むだけです。

> codex-bridge で、○○の開発を依頼して

エージェントが自分で手順を確かめ、共有フォルダを見て具体的な依頼文にし、知人の Codex に送り、承認待ちには内容を確かめて応え、結果を確認して報告します。
承認・権限・共有フォルダ・招待コードなど、管理画面でできることは、すべてエージェントにも頼めます（「scripts フォルダを書けるようにして」など）。

**2. 管理画面から直接頼む**
「Codex に依頼する」欄に書いて「依頼する」。タスクを選んで「続きとして依頼する」にチェックすると、前の会話の続きになります。
作業中のタスクには、詳細の欄から追加の指示を送ったり、中止したりできます。

### 管理画面でできること

| 欄 | できること |
|---|---|
| 使用量 | 知人の Codex の 5 時間枠・週間枠の使用率。しきい値を超えると、作業中の Codex に区切りで止めるよう頼み、新しい依頼を止めます。知人が決めた上限もここに表示されます（低いほうが効きます） |
| 状態 | 共有フォルダの変更（「変更」→ パスを入力か「参照…」）、知人に見せるログの範囲 |
| 確認待ち | コマンド実行・削除の許可／拒否（エージェントも内容を確かめて応えます。30 分放置で自動拒否） |
| Codex に依頼する／タスク | 直接の依頼、追加の指示、中止、変更の取り消し |
| 権限 | フォルダごとの「見せない／読むだけ／書ける」、コマンド実行の扱い、削除の承認 |
| 招待コード | 発行・失効 |
| 右上 | 全体の一時停止 |

## C. Tailscale の準備

1. https://tailscale.com/download から Windows 版を入れる
2. タスクトレイの Tailscale のアイコンを右クリック →「Log in...」→ Google などでログイン →「Connect」
3. アイコンを右クリックして「Connected」と出ていれば完了

---

## D. 困ったとき

| 症状 | 対処 |
|---|---|
| 管理画面が「未接続」のまま | 知人の PC で CB アイコンが出ているか／両方の Tailscale が Connected か／知人が共有の招待を受け入れたか |
| `start.bat` が「起動できませんでした」 | Tailscale が Connected か。前の `start.bat` のウィンドウが残っていないか（あれば `stop.bat`） |
| エージェントが codex-bridge を使わない | `start.bat` で起動しているか。`install-mcp.bat` のあとに**新しい会話**を始めたか |
| 知人の PC で「接続を断られました」 | 招待コードが失効・発行し直されている。新しいコードを渡す |
| 知人の PC でエラーの画面が出た | `%LOCALAPPDATA%\codex-bridge-agent\logs\crash.log` を送ってもらう |
| 変更を取り消したい | エージェントに「さっきのタスクの変更を取り消して」、または管理画面のタスク詳細の「このタスクのファイル変更を取り消す」 |
