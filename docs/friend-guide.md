# codex-bridge の使い方（Codex を貸してくれる方へ）

この手順で、依頼主があなたの PC の Codex に作業を頼めるようになります。
依頼されたファイルの読み書きは、依頼主が共有したフォルダを、依頼主の道具を通して行います。あなたの普段のファイルを作業の対象にはしません。

v0.2 では、自分の画面で依頼や作業の記録を見て、使わせる範囲や保存場所を決められます。

## 用意するもの

依頼主から次の 3 つを受け取ってください。

1. `codex-bridge-agent.exe`（好きなフォルダに置いてかまいません。例: デスクトップ）
2. Tailscale の共有の招待リンク
3. 招待コード（`cbx1.` で始まる長い文字列。メモ帳などに貼って保存しておくと安心です）

招待コードは、貸す人ごとに別のものを受け取ります。依頼主は複数の人に頼めますが、あなたが受け持つ作業は同時に 1 つです。終わったあとの続きの依頼も、同じ人の Codex に届きます。

あなたの PC に必要なのは、Tailscale と、Codex の ChatGPT アカウントだけです。Codex のデスクトップ版しか入っていなくても大丈夫です（コマンド版は codex-bridge が自動で取得します）。

## 1. Tailscale を入れる

1. https://tailscale.com/download から Windows 版を入れます。
2. 起動してアカウントを作り、ログインします（Google アカウントなどで作れます）。
3. 依頼主から受け取った「共有の招待リンク」を開き、受け入れます。

※ 共有されるのは依頼主の PC 1 台だけです。依頼主からあなたの PC に接続することはできません。

**つながったかの確かめ方：** 依頼主が準備できたと言ったら、ブラウザで依頼主から聞いた住所（例: `http://100.x.x.x:8765/codex/mcp`。100.x.x.x は依頼主の PC の Tailscale の IP）を開きます。`unauthorized` と表示されれば、通信は届いています（合言葉なしで開いたので断られた、という意味で正常です）。

## 2. codex-bridge-agent を起動する

1. `codex-bridge-agent.exe` をダブルクリックします。
   （「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」）
2. 「招待コードを貼り付けてください」と出たら、招待コードを貼り付けて OK を押します。
3. Codex（コマンド版）が入っていない場合は、ダウンロードしてよいか聞かれます。「はい」を押してください（約 200MB、公式の GitHub から取得します）。
4. 最初の依頼を受けたとき、Codex にまだログインしていなければログインの画面が開きます。案内に従って ChatGPT でログインしてください。

起動すると、画面右下（タスクトレイ）に青い「CB」のアイコンが出ます。

## タスクトレイのアイコン

アイコンを右クリックすると、次の操作ができます。

| メニュー | 内容 |
|---|---|
| 状態 | 接続できているかどうか |
| 画面を開く | 使用量・依頼・作業の記録・セッションの確認と設定 |
| 一時停止する／再開する | 依頼主との接続を一時的に止める／つなぎ直す |
| 終了 | codex-bridge を終了する |

## 自分の画面を見る

CB アイコンを右クリック →「画面を開く」で、ブラウザに `http://127.0.0.1:8766/` が開きます。exe を動かしている間、自分の PC で開ける画面です。

| 欄 | 見られること・できること |
|---|---|
| 使用量 | 5 時間枠・週間枠の使用率と戻る時刻、あなたの上限の保存。上限はすべての接続先に共通です |
| 接続先 | 依頼主ごとの接続・作業の状態、招待コードの追加・入れ直し・接続先を外す操作、接続先ごとの設定 |
| 事前承認待ち | 依頼文を読んで「許可」「拒否」。拒否の理由も書けます |
| タスク | 一覧から選ぶと、依頼文・途中経過・計画・最終報告・記録を表示。「簡易／詳細」の切り替えや、記録の絞り込み・検索 |
| セッション | このツールで作った会話だけの一覧。選ぶと、その会話のタスクに絞ります。作業中の会話は削除できません |
| 共通の設定 | 保存場所、作業フォルダ、記録の保管日数 |
| 右上 | 一時停止・解除（依頼主との接続を止める／つなぎ直す） |

「接続先」には、依頼主の名前ではなく PC の住所（例: `100.x.x.x:8765`）が出ます。
依頼文・追加の指示・Codex の発言と計画・状態・最終報告は、いつも見られます。道具の記録は、接続先の「設定」で「非表示／道具の名前と対象パス／結果の本文まで」を選べます。
「詳細」には、届いていれば考えの要約や使ったトークン数も出ます。**今の Codex では、考えの要約は空のことがよくあります。**

## 使用量の上限を決める

依頼主の作業は、あなたの Codex の使用量（5 時間枠・週間枠）を使います。どこまで使わせるかは、あなたが決められます。

1. タスクトレイの CB アイコンを右クリック →「画面を開く」
2. 使用量の棒の横の「あなたの上限」に、5 時間枠・週間枠それぞれの使用率（1〜100%）を入れる（初期値は両方 80%。空欄なら依頼主の設定だけが使われます）
3. 「超えたらすぐ強制的に止める」を選ぶ
   - オン: 超えた時点で、依頼主の作業をすぐ止めます
   - オフ: Codex に「区切りのよいところで止めて報告して」と頼みます（止まるまでに少し使用量が増えることがあります）
4. 使用量欄の「保存」（すぐにすべての接続先に効きます。依頼主の設定より低ければ、あなたの設定が使われます。強制停止の初期値はオフです）

## 接続先を追加・入れ直し・外す

複数の依頼主に、1 つの exe から Codex を貸せます。「接続先を追加」に別の招待コードを貼り付け、「追加」を押してください。同じ接続先を二重には登録できません。

コードが失効すると、その接続先の行が赤くなります。依頼主から新しいコードをもらい、「招待コードを入れ直す」の欄に貼り付けて「入れ直す」を押します。設定と会話の一覧は引き継ぎます。
「外す」は、その接続先との接続と、この PC にあるその接続先の設定・会話の一覧・作業の記録を消します。Codex 自身が保存した会話や、依頼主側の記録は消しません。作業中・承認待ちの接続先は、入れ直し・外す操作ができません。別の接続先が作業中でも、待機中の接続先は変更できます。
入れ直したコードの住所や招待名が前と異なる場合、以前の会話を新しい依頼主へ渡さないため、会話の一覧を分けます。この画面の過去の作業の記録は残します。

作業は、すべての接続先を合わせて同時に **1 つ** です。承認待ちのあいだも、ほかの依頼主には「ほかの依頼主の作業中」と伝わります。あとから届いた依頼は順番待ちにせず断るので、作業が終わってから頼み直してもらってください。

各接続先の「設定」では、機能の制限・事前承認・セッションの使い捨て・道具の記録の見せ方を、その依頼主にだけ設定します。上限と止め方・保存場所・作業フォルダ・記録の保管日数は共通です。
タスク・承認待ち・セッションには依頼主の住所が表示され、「依頼主で絞り込む」で選んだ接続先だけを見られます。
以前の版から初めて起動したときは、保存済みの招待コード・接続先の設定・会話の一覧・作業の記録を最初の接続先に引き継ぎます。

## 使える機能を決める

接続先の「設定」の「使える機能の制限」で、止めたい機能にチェックし、「設定を保存」を押します。初期値は、次の 4 つすべてにチェックが入っています。

- Web 検索・Web の取得
- 画像生成
- サブエージェント（複数エージェント）
- 目標（goal）機能

**サブエージェントを止める設定は、ベストエフォートです。** 今の Codex には確実に止める設定がなく、「使わないで」と頼む形なので、チェックしても使われることがあります。
機能の変更は、作業中でなければ Codex を起動し直して反映します。作業中なら、その作業が終わってから反映します。あなたが普段使う Codex の設定は書き換えません。

## 依頼を見てから許可する（事前承認）

接続先の「設定」の「事前承認」で「依頼主からの依頼を、私が許可してから始める」を選び、「設定を保存」を押します（初期値は「そのまま始める」）。
新しい依頼も追加の指示も、Codex に渡す前に止めて、画面に「許可」「拒否」を出します。タスクトレイでも知らせます。ブラウザの通知は「承認待ちのブラウザ通知を有効にする」から使えます。
承認の待ち時間は初期値 30 分で、1〜1440 分に変えられます。時間が過ぎると拒否します。「待ち時間なし」なら、許可か拒否を選ぶまで待ちます。待っている途中で設定を変えても、その依頼の待ち時間は変わりません。

## 会話を残す・使い捨てにする

接続先の「設定」の「セッションの保存」で選び、「設定を保存」を押します。初期値は「セッションを残す」です。

- **セッションを残す** … 終わったあとも、依頼主が前の会話の続きを頼めます。「セッション」欄から、このツールで作った会話を削除できます。
- **セッションを使い捨てにする** … 新しく始める作業は、Codex の会話の記録を作りません。完了・中止・失敗・使用量による中断のあと、その会話は一覧からも消え、続きは頼めません。作業中の追加の指示は使えます。

使い捨てにしても、下の「作業の記録」は残ります。セッションの削除でも、作業の記録は消えません。

## 作業の記録を残す・消す

記録は接続先・タスクごとに、データの保存場所の `connections\<接続先の ID>\logs\tasks\` に残します。共通の設定の「作業の記録」で、保管日数を 1〜3650 日に変えられます（初期値は 30 日）。起動時と作業の開始時に、保管期間を過ぎた古い記録を消します。
「記録を消す」を押すと、この PC の作業の記録をまとめて消せます。会話と設定、依頼主の PC 側の記録は残ります。

接続先ごとに決める道具の表示範囲は、この画面で見せる範囲です。保存場所の作業ログには、道具の記録も残ります。

## データの保存場所を変える

初期の場所は `%LOCALAPPDATA%\codex-bridge-agent` です。エクスプローラーの住所欄に入れると開けます。
ここには、招待コード（暗号化済み）・設定・セッションの一覧・作業の記録・ダウンロードした Codex（`bin\`）を置きます。作業フォルダをこの中に置く場合は、それも含みます。

1. 作業と事前承認待ちが終わっていることを確かめます。
2. 設定の「codex-bridge のデータの保存場所」に、移動先の空のフォルダのフルパス（例: `D:/codex-bridge-data`）を入れます。まだないフォルダも指定できます。
3. 「移して起動し直す」を押します。データを移したあと、**exe が自分で再起動します。**

移動先は `%LOCALAPPDATA%\codex-bridge-agent\location.txt` に記録します。このファイルは元の場所に残すので、削除しないでください。別に指定した作業フォルダは、その場所を使い続けます。

この操作では、Codex 自身の保存場所（`~/.codex`、通常は `%USERPROFILE%\.codex`）は変わりません。Codex の状態の記録・ログ・モデルの一覧の控え・一時ファイル・通常の会話の記録は、そこに残ります。使い捨てなら会話の記録は作りませんが、それ以外の小さな共有ファイルは残ります。

## 作業フォルダの場所を決める

依頼主のファイルは依頼主の PC に置いたまま、こちらでは Codex を空の作業フォルダで動かします。既定は `C:\ProgramData\codex-bridge-agent\work-<ランダム>` で、作れない場合はデータの保存場所の `workdir` を使います。
設定の「作業フォルダの場所」にフルパスを入れ、「設定を保存」で変えられます。空欄なら既定の場所です。作業中に変えた場合は、終わってから反映します。指定先を使えなければ既定の場所を使うので、「現在」の表示で確かめてください。
ユーザー名を含むパスは Codex の前提情報に入り、依頼主に伝わることがあるので、ユーザー名を含まない場所がおすすめです。

## よくある質問

- **使用量はどうなりますか？** 依頼主の作業は、あなたの Codex の使用量を使います。上の「使用量の上限を決める」で、どこまで使わせるか決められます。
- **依頼主の作業で、自分の普段のファイルは書き換わりますか？** 依頼されたファイルの読み書きは、依頼主の共有フォルダを扱う道具を通して行います。あなたが Codex に登録している MCP サーバーやプラグイン、コマンド実行・画面操作などは、依頼主の作業では使えないようにしています（あなたが普段使う Codex の設定は書き換えません）。
- **自分でも Codex を使えますか？** 使えます。ただし使用量の枠は共有になります。
- **やめたいときは？** トレイのアイコンから「終了」してください。依頼主に招待コードを失効してもらえば、二度と接続されません。
- **記録はどこにありますか？** 上の「データの保存場所」にあります。招待コードは Windows の機能で暗号化して保存しています。今の場所は自分の画面の設定で確かめられます。
- **毎回どうすればいいですか？** 依頼主が「作業を頼みたい」と言ったら、`codex-bridge-agent.exe` をダブルクリックするだけです（2 回目からは招待コードの入力はありません）。PC の起動時に自動で動かしたい場合は、exe のショートカットを `shell:startup`（エクスプローラーの住所欄に入力）のフォルダに置きます。
- **新しい招待コードをもらったら？** トレイから「終了」→ データの保存場所の `invite.bin` を削除 → exe を起動すると、入力画面がもう一度出ます。保存場所を変えていなければ `%LOCALAPPDATA%\codex-bridge-agent\invite.bin` です。
- **「接続を断られました」と出る** 招待コードが失効しています。依頼主に新しいコードをもらってください。
- **エラーの画面が出た** 画面に出た `crash.log` を依頼主に送ってください。初期の場所は `%LOCALAPPDATA%\codex-bridge-agent\logs\crash.log`、移動した場合は新しい保存場所の `logs\crash.log` です。
- **v0.1 から更新するときは？** 先に依頼主側を v0.2 に更新してもらい、それからこちらの exe を更新してください。v0.1 の exe のままでも v0.2 の依頼主側につなげられますが、この手順の新しい画面と設定には v0.2 の exe が必要です。
メイン以外のフォルダを使うには、こちらの exe も v0.2 が必要です（v0.1 の exe はメインのフォルダだけで作業できます）。
