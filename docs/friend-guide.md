# codex-bridge の使い方（Codex を貸してくれる方へ）

この手順で、依頼主があなたの PC の Codex に作業を頼めるようになります。
依頼されたファイルの読み書きは、依頼主が共有したフォルダを、依頼主の道具を通して行います。あなたの普段のファイルを作業の対象にはしません。

v0.3.0 では、「貸す」タブで依頼や作業の記録を見て、依頼主ごとに使える範囲を決められます。

## 用意するもの

依頼主から次の 3 つを受け取ってください。

1. codex-bridge の zip（`codex-bridge-v` で始まる名前）。右クリック →「すべて展開」で展開し、中の `codex-bridge.exe` だけを使います。画面の「貸す」タブからつなぎます
2. Tailscale の共有の招待リンク
3. 招待コード（`cbx1.` で始まる長い文字列。メモ帳などに貼って保存しておくと安心です）

招待コードは、貸す人ごとに別のものを受け取ります。あなたも同時に複数の依頼を受けられます。受ける数は「貸す」タブで決めます（既定 3、1〜8）。終わったあとの続きの依頼も、同じ人の Codex に届きます。

あなたの PC に必要なのは、Tailscale と、Codex の ChatGPT アカウントだけです。Codex のデスクトップ版しか入っていなくても大丈夫です（コマンド版は codex-bridge が自動で取得します）。

## 1. Tailscale を入れる

1. https://tailscale.com/download から Windows 版を入れます。
2. 起動してアカウントを作り、ログインします（Google アカウントなどで作れます）。
3. 依頼主から受け取った「共有の招待リンク」を開き、受け入れます。

※ 共有されるのは依頼主の PC 1 台だけです。依頼主からあなたの PC に接続することはできません。

**つながったかの確かめ方：** 依頼主が準備できたと言ったら、ブラウザで依頼主から聞いた住所（例: `http://100.x.x.x:8765/codex/mcp`。100.x.x.x は依頼主の PC の Tailscale の IP）を開きます。`unauthorized` と表示されれば、通信は届いています（合言葉なしで開いたので断られた、という意味で正常です）。

## 2. codex-bridge を起動してつなぐ

1. 展開したフォルダの `codex-bridge.exe` をダブルクリックします。
   （「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」）
2. タスクトレイの CB アイコンを左クリックするか、右クリック →「画面を開く」で http://127.0.0.1:8766/ を開きます。「使う」「貸す」「ログ」のタブがあります。
3. 「貸す」タブに、依頼主からもらった招待コードを貼り、「つなぐ」を押します。
4. Codex（コマンド版）が入っていなければ、ダウンロードしてよいか聞かれます。「はい」を押してください（約 200MB、公式の GitHub から取得します）。
5. Codex にまだログインしていなければ、案内に従って ChatGPT でログインします。つながったら、使用量を確認してください。

exe はタスクトレイに常駐します。2 回目からは、保存した接続先につなぎ直します。すでに動いているときにもう一度 exe を開くと、そのアプリの画面が開きます。

## タスクトレイのアイコン

左クリックで画面を開けます。右クリックでは、次の操作ができます。

| メニュー | 内容 |
|---|---|
| 状態 | 貸す人・依頼主との接続数と承認待ちの数 |
| 画面を開く | 「使う」「貸す」「ログ」の画面を開く |
| 一時停止／再開 | アプリ全体を一時停止する／再開する |
| 終了 | codex-bridge を終了する |

## 自分の画面を見る

「貸す」タブには、次の欄があります。

| 欄 | 見られること・できること |
|---|---|
| 使用量 | 5 時間枠・週間枠の使用率、戻る時刻、上限と超えたときの止め方 |
| 依頼主 | 依頼主ごとの接続・作業の状態。カードを開くと、その依頼主だけの設定 |
| 許可を待っている依頼 | 依頼文を読んで「許可」「拒否」。拒否する理由も書けます |
| 依頼 | 一覧から選ぶと、依頼文・途中経過・計画・最終報告を表示。依頼主で絞り込めます |
| この PC | 作業フォルダ、記録を残す日数、データの場所 |

依頼主のカードには、名前の代わりに PC の住所（例: `100.x.x.x:8765`）が出ます。依頼文・追加の指示・Codex の発言と計画・状態・最終報告は、いつも見られます。道具の記録は、カードの「この画面に出す記録」で「道具の名前と対象」「道具の結果」を選びます。何も選ばなければ「なし」です。「道具の結果」を選ぶと「道具の名前と対象」も入ります。

設定は変更すると反映されます。保存ボタンはありません。アプリの接続や失敗の記録は「ログ」タブで確認できます。使う側・貸す側の絞り込み、検索、書き出し、保存フォルダを開く操作ができます。

## 使用量の上限を決める

依頼主の作業は、あなたの Codex の使用量（5 時間枠・週間枠）を使います。上限を決めるのは貸す人です。

1. 「貸す」タブの「使用量」で、「5時間の上限」「週間の上限」に 1〜100% を入れます。初期値はどちらも 80%、空欄は上限なしです。
2. 「上限を超えたとき」を選びます。
   - 「止めて報告させる」: Codex に作業を止めて報告するよう頼みます。報告の分だけ使用量が増えることがあります。初期値はこちらです。
   - 「すぐ強制終了」: 超えた時点で作業をすぐ止めます。

変更はすべての依頼主に共通です。使用量の上限に達すると、作業中のすべての依頼に選んだ止め方を適用し、新しい依頼も止めます。

## 依頼主を追加・招待コードを入れ直す・外す

複数の依頼主に、1 つの exe から Codex を貸せます。「貸す」タブの「依頼主」横の「追加」を押し、別の招待コードを貼って「つなぐ」を押してください。同じ接続先を二重には登録できません。

コードが失効すると、カードに「招待コードが無効」と表示します。依頼主から新しいコードをもらい、そのカードの「招待コードを入れ直す」を押し、貼って「つなぐ」を押します。設定と会話の一覧は引き継ぎます。
「外す」は、その接続と、この PC にあるその依頼主の設定・会話の一覧・作業の記録を消します。Codex 自身が保存した会話や、依頼主側の記録は消しません。作業中・承認待ちの接続先は、入れ直し・外す操作ができません。別の依頼主の作業中でも、待機中の接続先は変えられます。
コードの住所や招待名が前と異なる場合は、以前の会話を新しい依頼主へ渡さないため、会話の一覧を分けます。過去の作業の記録は残します。

「貸す」タブの使用量の下にある「同時に受ける依頼」で、1〜8 件から上限を選べます（既定 3）。許可待ちも含め、すべての依頼主の合計で数えます。上限に達していると新しい依頼を断り、空きができると再び受け付けます。上限を下げても、すでに受けた依頼は続けます。
以前の版から初めて起動したときは、保存済みの招待コード・設定・会話の一覧・作業の記録を最初の接続先に引き継ぎます。

## 依頼主ごとの設定

「貸す」タブで依頼主のカードを開き、設定を変えます。

| 設定 | 内容 |
|---|---|
| 使えるモデル | この依頼主が使えるモデルを選ぶ。初期値はすべて |
| 推論の強さの上限 | 初期値は xhigh。上限の範囲に合うモデルだけを依頼主に表示 |
| 始める前の許可 | 「新しい依頼」「追加の指示」を別々に選ぶ。初期値はどちらもオフ |
| 続きの依頼 | オンなら会話を残し、終わったあとの続きも受ける。初期値はオン |
| Web 検索／画像の生成／サブエージェント／目標 | 使える機能を選ぶ。初期値はすべてオフ |
| この画面に出す記録 | 道具の名前と対象・道具の結果の表示範囲 |
| 記録 | この依頼主の作業の記録を消す |
| つなぎ方 | 招待コードを入れ直す、依頼主を外す |

機能の変更は、作業中でなければ Codex を起動し直して反映します。作業中なら終わってから反映します。あなたが普段使う Codex の設定は書き換えません。
**サブエージェントの制限はベストエフォートです。** 今の Codex では確実には止められません。

### 依頼を見てから許可する

「始める前の許可」で選んだ依頼は、Codex に渡す前に止め、画面に「許可」「拒否」を出します。タスクトレイでも知らせます。
待ち時間の初期値は 30 分で、1〜1440 分に変えられます。空欄なら、許可か拒否を選ぶまで待ちます。途中で設定を変えても、待っている依頼の期限は変わりません。

### 会話を残す・使い捨てにする

「続きの依頼」をオフにすると、新しく始める作業の会話を使い捨てにします。終わったあとの続きは受けられませんが、作業中の追加の指示は受けられます。作業の記録は残ります。
このツールで作った会話の一覧や削除は、依頼主が Claude Code / Codex の会話管理の道具から行えます。作業中の会話は削除できません。

## 作業の記録を残す・消す

「貸す」→「この PC」の「記録を残す日数」で、1〜3650 日に変えられます（初期値は 30 日）。起動時と作業の開始時に、保管期間を過ぎた記録を消します。
各依頼主のカードの「記録を消す」で、その依頼主の作業の記録を消せます。会話と設定、依頼主の PC 側の記録は残ります。

記録はデータの場所の `connections/<接続先の ID>/logs/tasks/` にあります。画面での道具の表示範囲を変えても、保存する作業ログには道具の記録が残ります。

## データの保存場所を変える

初期の場所は `%LOCALAPPDATA%\codex-bridge-agent` です。招待コード（暗号化済み）・設定・会話の一覧・作業の記録・ダウンロードした Codex を置きます。

1. 作業と承認待ちが終わっていることを確かめます。
2. 「貸す」→「この PC」の「データの場所」で「移す」を押し、空のフォルダのフルパス（例: `D:/codex-bridge-data`）を入れます。まだないフォルダも指定できます。
3. 「移す」を押します。データを移すと、exe が自分で起動し直します。

元の場所の `location.txt` は移動先を記録するために残すので、削除しないでください。別に指定した作業フォルダと、Codex 自身の `~/.codex` はそのままです。

## 作業フォルダの場所を決める

依頼主のファイルは依頼主の PC に置いたまま、Codex を空の作業フォルダで動かします。既定は `C:\ProgramData\codex-bridge-agent\work-<ランダム>` で、作れない場合はデータの場所の `workdir` を使います。
「貸す」→「この PC」の「作業フォルダ」で「変える」を押し、フルパスを入れて「変える」を押します。空欄なら既定の場所です。作業中に変えた場合は、終わってから反映します。
ユーザー名を含むパスは Codex を通して依頼主に伝わることがあるので、ユーザー名を含まない場所を選んでください。

## よくある質問

- **自分でも Codex を使えますか？** 使えます。ただし使用量の枠は共有です。
- **やめたいときは？** トレイの「終了」を押します。依頼主に招待コードを取り消してもらえば、そのコードでは接続できなくなります。
- **毎回どうすればいいですか？** `codex-bridge.exe` をダブルクリックします。保存済みの接続先につなぎ直すので、コードを貼り直す必要はありません。
- **PC の起動時に動かすには？** `codex-bridge.exe` のショートカットを作り、エクスプローラーの住所欄に `shell:startup` と入れて開いたフォルダに置きます。リンク先は exe のフルパスだけで、引数は要りません。サインインするとタスクトレイに常駐し、保存した接続先につなぎ直します。
- **つながりません** 両方の Tailscale が Connected か、共有の招待を受け入れたかを確かめます。「招待コードが無効」なら、依頼主に新しいコードをもらい、カードから入れ直してください。「ログ」タブでも原因を確認できます。
- **エラーの画面が出た** 画面に出た `crash.log` を依頼主に送ってください。初期の場所は `%LOCALAPPDATA%\codex-bridge-agent\logs\crash.log`、移動後は新しい場所の `logs/crash.log` です。
- **以前の版から更新するときは？** 依頼主から先に v0.3.0 に更新してください。この版の画面と設定には、貸す人も v0.3.0 の exe が必要です。v0.2 の exe はモデルと推論の強さを指定した依頼を受けられません。v0.1 の exe はメインの共有フォルダだけで作業できます。
