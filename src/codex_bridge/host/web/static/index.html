共有フォルダ

    「参照…」を押すと、この PC にフォルダを選ぶ画面が開きます。 フォルダの追加・削除・メインの切り替えは、すぐに反映されます（作業中のタスクがあるときは変えられません）。
    「メイン」は、相対パスで書かれた場所の起点になるフォルダです。 ▸ を押すと、中のフォルダごとに権限を決められます。「上と同じ」は、ひとつ上のフォルダの設定に従います。 権限の変更は、「保存して反映」を押すと反映されます。

    コマンド実行（Codex が共有フォルダでプログラムを動かすこと）

    自動で実行してよいコマンド（1 行に 1 つ）

    例: python scripts/**/*.py * … scripts フォルダの中の .py を、どんな引数でも実行してよい。
    * = 名前の一部または「任意の引数」、** = 下のフォルダすべて。&& や | を含むコマンドは、リストに合っても承認待ちになります。

    削除

    ⚠ コマンド実行は閉じ込めていません。実行されたスクリプトは「見せない」場所や共有フォルダの外も読めます。
