使用量

依頼主の作業は、あなたの Codex の使用量を使います。あなたの上限と依頼主のしきい値のうち、低いほうが効きます。空欄なら依頼主のしきい値だけが効きます。

codex-bridge のデータの保存場所

現在:
初期値: %LOCALAPPDATA%\codex-bridge-agent

招待コード（暗号化済み）・設定・セッションの一覧・記録（ログ）・作業フォルダ・ダウンロードした Codex（bin\）を置きます。変更するとデータを移し、exe を起動し直します。

保存場所を記録する %LOCALAPPDATA%\codex-bridge-agent\location.txt は移しません。別に指定した作業フォルダは、その場所を使い続けます。

codex-bridge では場所を変えられないもの

Codex 自身が ~/.codex の下に書くもの: 状態の記録（sqlite）、ログ、モデルの一覧の控え、一時ファイル、通常のセッションの会話の記録。

使い捨てにすれば、会話の記録は作られません。それ以外の小さな共有ファイルは残ります。完全に分けるには Codex の設定フォルダ（CODEX_HOME）を分ける必要がありますが、ログイン情報の扱いに未確認の点があるので、v0.2 では行いません。

起動時に使う %TEMP%\_MEI… は、終了時に消えます。
